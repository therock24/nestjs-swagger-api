# NestJS Swagger

A NestJS API with Swagger and custom Theme. Work in progress.

```bash
npm i

npm run start:dev
```

Open Swagger API in your browser [localhost:3000/api](http://localhost:3000/api).

## Branches

main - the production branch. will be deployed to a public host.
develop - the latest development version. all features branches are merged into here
feat/xx - a feature branch, implementing a specific feature (e.g. authentication)
